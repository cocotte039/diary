## 実装概要
- `useParams<{memoId?: string}>()`。`/log/new`=新規（memoId undefined）、`/log/:memoId`=編集。
- 編集: `getMemo(memoId)` undefined → `navigate('/log',{replace:true})`（幽霊メモ回避, E10）。あれば content を state 初期化。
- textarea: **罫線なしプレーン**（日記=罫線ノート / メモ=素の紙で体験分離）。明朝フォント。自動フォーカスなし（マウント時 focus しない, 静けさ）。
- ヘッダー: 左 `.app-header-link` 戻る。新規=遷移元（`location.state?.from` or 既定 `/`）、編集=`/log`。編集時ヘッダー右に createdAt 控えめ表示（`YYYY/MM/DD HH:MM`, 0.7rem, opacity 0.3）。新規未保存時は非表示。
- popstate ガード（EditorPage 同型・StrictMode 二重 pushState 防止 ref）→ flush→ navigate(戻り先,{replace}).
- `useMemoAutoSave(memoId ?? null, content, (id)=>navigate('/log/'+id,{replace:true}))` 配線。
- 戻るリンク click 時に `await flush()` してから navigate。

## 受入条件（TDD）
- 🔵 `/log/new` で textarea 入力→debounce 後 addMemo 1件、URL が `/log/:id` に replace
- 🔵 `/log/new` で未入力のまま戻る→ getAllMemos 0件（U3）
- 🔵 `/log/:memoId`（既存）で content ロード表示、編集→ updateMemo、updatedAt 更新
- 🔵 `/log/不正id`→`/log` replace 遷移
- 🔵 戻る/popstate で flush 後遷移（直近入力が保存）
- 🔵 マウント時 textarea が `document.activeElement` でない（自動フォーカスなし）
- 🟡 編集時 createdAt 控えめ表示あり、新規未保存時なし
- 🔵 罫線 CSS を使わない（notebook.css の罫線クラス不使用）
- 🔵 `npm run test:run` 緑
