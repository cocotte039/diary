# M1-T1: MemoEditorPage textarea に notebook クラス付与

## 変更対象
- `src/features/log/MemoEditorPage.tsx`

## 実装概要
textarea の `className={styles.textarea}` を `` className={`notebook-surface notebook-textarea ${styles.textarea}`} `` に変更（EditorPage.tsx L391 と同パターン）。これで Klee One フォント＋日記同等の罫線（repeating-linear-gradient）が適用される。
ファイル冒頭の設計意図コメント（L26-36 の「罫線なしプレーン textarea（日記=罫線ノート / メモ=素の紙で体験分離）」記述）を「ユーザー要望により日記と体験統一（Klee One＋罫線）。自由高さは維持（メモにページ概念は導入しない）」へ更新。

## 依存する既存コード
- `src/styles/notebook.css` の `.notebook-surface` / `.notebook-textarea`（不変・流用のみ）
- `styles.textarea`（MemoEditorPage.module.css、M1-T2 で減算）
- `.surface` ラッパは不変（自由高さスクロール維持）
