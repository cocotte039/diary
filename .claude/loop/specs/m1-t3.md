## 実装概要
- `addMemo`: `id=uuid()`, `createdAt=updatedAt=nowIso()`, `syncStatus='pending'`、put、返却。
- `updateMemo`: `get`→無ければ **no-op で undefined**（削除済みを put で復活させない, E18）。あれば `content`/`updatedAt=nowIso()`/`syncStatus='pending'` 更新。
- `getAllMemos`: 全件（呼び側でソート。または createdAt 昇順返却でも可、LogListPage で降順整形）。
- `deleteMemo`（A12 込み）: 対象削除 → 同 `dateKey(createdAt)` の他メモが残る場合そのうち1件を `syncStatus='pending'` 化（当日ファイル再生成誘発）。当日メモが全滅なら `addDeletedMemoDay(dateKey)`。
- `memos-deleted-days`: meta KV に `string[]`（重複排除）。get/add/remove。
- `markMemosSyncedByDay(dateKey, ids)`: 指定 id のみ `syncStatus='synced'`（生成時 id 集合のみ, E3）。
- `replaceAllData`: 第3引数 `memos?` 追加。**未指定時は memos ストアに一切触れない**（U2）。指定時のみ memos clear→再投入。volumes/pages 既存処理は不変。

## 受入条件（TDD）
- 🔵 addMemo→getMemo 往復一致、`createdAt===updatedAt`、`syncStatus==='pending'`
- 🔵 updateMemo: 存在 id で content/updatedAt 更新・syncStatus pending、`updatedAt>createdAt`（または >=）
- 🔵 updateMemo: 不在 id で undefined・DB 件数不変
- 🔵 deleteMemo: getMemo undefined。当日他メモありなら1件 pending 化。当日全削除なら getDeletedMemoDays に当日 dateKey 含む
- 🔵 getPendingMemos: pending のみ返す
- 🔵 markMemosSyncedByDay: 渡した id のみ synced、他は pending 維持
- 🔵 getDeletedMemoDays/add/remove: 重複追加しても1要素、remove で消える
- 🔵 replaceAllData(volumes,pages)（memos 省略）→ 既存 memos 件数不変
- 🔵 replaceAllData(volumes,pages,memos)（指定）→ memos 置換
- 🔵 `npm run test:run` 緑

## テスト方針
db.test.ts に memo CRUD 全関数・A12 誘発・replaceAllData memos 保持/置換・deleted-days を網羅。fake-indexeddb、wipeDB beforeEach。

## 注意
- `nowIso`/`uuid` 既存 private ヘルパ流用。
- meta ストアは既存汎用 KV。キー名 `'memos-deleted-days'` 定数化（constants かファイル内 const）。
- A12 の「他メモ1件 pending 化」は createdAt 最新など決定的に1件選ぶ（テスト安定）。
