# M1-T2: MemoEditorPage.module.css .textarea を notebook へ委譲（減算）

## 変更対象
- `src/features/log/MemoEditorPage.module.css`

## 実装概要
`.textarea` から notebook-surface/notebook-textarea が提供する宣言を削除（委譲）。
削除対象: `border:none` `outline:none` `resize:none`（notebook-textarea）/ `font-family` `font-size` `line-height` `letter-spacing`（notebook-surface）/ `padding`（上下左右すべて。notebook-surface の `padding:0 var(--padding-page)` に委譲、独自再付与禁止＝罫線ベースライン整合 C2）。
`.textarea` に残す宣言: `flex:1 1 auto; width:100%; background-color:var(--color-bg); color:var(--color-text); -webkit-tap-highlight-color:transparent;`
（`.notebook-surface` も bg/color を持つが MemoEditorPage 固有レイアウト保持のため flex/width は残す。bg/color は重複しても無害だが notebook と同値なので残置可）。
冒頭コメントの「罫線なしの素の紙」記述を体験統一に更新。`.surface` は不変。

## 依存する既存コード
- notebook.css `.notebook-surface`（padding:0 var(--padding-page) / font 一式 / 罫線 / background-attachment:local）
- `.surface`（flex:1 1 auto; min-height:0; overflow-y:auto; display:flex）= 自由高さスクロール、不変

## 受入条件
- [ ] 🔵 `.textarea` に font-family/font-size/line-height/letter-spacing 宣言が無い
- [ ] 🟡 `.textarea` に上下 padding の独自指定が無い（C2 罫線ベースライン）
- [ ] 🔵 `.textarea` に border/outline/resize 独自指定が無い
- [ ] 🔵 `.surface` 不変（自由高さ維持・var(--page-height-px)/min-height 60行を導入しない）
- [ ] 🟡 実機: 1行目テキスト下端と1本目罫線整合・スクロール時罫線追従・空メモ/長文罫線

## テスト方針
CSS のため vitest 検証不可。CSS 静的差分レビュー + 実機/preview 目視。MemoEditorPage.test.tsx 回帰のみ。

## 注意事項
左右 padding も notebook 委譲（safe-area は notebook 側 `padding:0 var(--padding-page)` で吸収。EditorPage と同型化）。独自に padding を再付与すると罫線位相がずれる（plan C2）。ロールバックは1コミット revert。
