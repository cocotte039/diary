## 実装概要（Aesthete 設計）
Fab.tsx: 右下固定の円形ボタン。
- `position: fixed; right: max(1rem, calc(env(safe-area-inset-right) + 0.5rem)); bottom: max(1.25rem, calc(env(safe-area-inset-bottom) + 0.75rem));`
- 52px 円、`background: var(--color-accent)`、`border: 1px solid var(--color-rule)`
- 鉛筆 SVG、`stroke: currentColor; stroke-width: 1.5`（BookshelfMenu のアイコン作法統一）
- press: `transform: scale(0.94); opacity: 0.8;` 150ms（≤200ms）
- `box-shadow: 0 2px 8px rgba(0,0,0,0.3)`
- `aria-label="メモを書く"`
- onClick: `navigate('/log/new', { state: { from: '/' } })`
BookshelfPage: `<Fab />` を配置。`.body` に `padding-bottom` を足し FAB がカード最下段に被らないようにする。

## 受入条件
- 🔵 FAB タップで `/log/new` 遷移（state.from='/'）
- 🔵 FAB は `position: fixed`（スクロール非追従）
- 🔵 4色のみ使用（新規色トークンなし）、トランジション≤200ms
- 🔵 `.body` padding-bottom でカード最下段が FAB に隠れない
- 🔵 aria-label 設定（アクセシビリティ）
- 🔵 `npm run lint && npm run test:run` 緑
