# M3-T3: SettingsPage を「閉じる」リンク化 + テスト

## 変更対象
- `src/features/settings/SettingsPage.tsx`
- `src/features/settings/SettingsPage.test.tsx`（既存。新規ケース追加。既存削除禁止）

## 実装概要
1. react-router-dom import に `useLocation` 追加（既存 `Link` と同行）。
2. コンポーネント先頭付近で `const from = (useLocation().state as { from?: string } | null)?.from ?? '/';`
3. ヘッダー L253 `<Link to="/" className="app-header-link">本棚</Link>` を
   `<Link to={from} className="app-header-link" aria-label="設定を閉じる">閉じる</Link>` に変更。

## 依存する既存コード
- `.app-header-link`（global.css）スタイル流用・不変
- location.state.from を BookshelfMenu(M3-T1='/')/MemoMenu(M3-T2='/log') が供給。直接URL/リロードは state なし→ '/' フォールバック（仕様・許容）

## 受入条件
- [ ] 🔵 state.from='/' → 「閉じる」リンク to が `/`
- [ ] 🔵 state.from='/log' → to が `/log`
- [ ] 🔵 state 無し（直接URL/リロード）→ to が `/`（fallback）
- [ ] 🔵 リンク文言が「閉じる」、className は `app-header-link` 維持
- [ ] 🔵 SettingsPage の他機能（export/github/同期等）不変
- [ ] 🔵 SettingsPage.test.tsx 全緑・既存テスト不変

## Key Links
- `useLocation()` （react-router-dom）→ SettingsPage 本番描画パスで `to={from}` に直接使用

## テスト方針（jsdom 可）
SettingsPage.test.tsx に MemoryRouter で `initialEntries=[{ pathname:'/settings', state:{ from:'/log' } }]` を渡し、「閉じる」リンク（getByText/role link）の `href`（HashRouter でなくテストは MemoryRouter 想定、既存テスト作法に合わせる）または `to` を検証。state 無しケースで '/' を検証。既存テストのレンダリングヘルパを流用。

## 注意事項
navigate(-1)/onClick は使わない（履歴汚染回避＝plan 裁定）。`<Link to={from}>` 直接遷移のみ。
