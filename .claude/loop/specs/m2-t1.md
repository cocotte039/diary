# M2-T1: メモ一覧本文を手書き体に

## 変更対象
- `src/features/log/LogListPage.module.css`

## 実装概要
`.preview` セレクタと `.emptyMemo` セレクタから `font-family: var(--font-family-ui);` の宣言行のみを削除する。これにより global.css body の `--font-family`（Klee One）を継承し、メモ一覧本文が日記と同じ手書き体になる。コメントの「ゴシック（可読性優先、日記の手書き体と差別化）」は「日記と同一の手書き体（ユーザー要望により世界観統一）」へ更新。

## 依存する既存コード
- global.css body: `font-family: var(--font-family)`（= 'Klee One' ...）を継承
- `.dateHeading` / `.time` / `.empty` は変更しない（UI メタ情報＝ゴシック維持・情報階層）

## 受入条件
- [ ] 🔵 `.preview` に font-family 宣言が無い
- [ ] 🔵 `.emptyMemo` に font-family 宣言が無い
- [ ] 🔵 `.dateHeading`/`.time`/`.empty` は `var(--font-family-ui)` のまま不変
- [ ] 🔵 一覧に罫線追加なし（背景・border 変更なし）
- [ ] 🟡 実機/preview で一覧本文が手書き体（Klee One）で表示（CSS のため vitest 検証不可）

## テスト方針
vitest は `css:false` のため CSS 検証不可。テスト追加なし。既存 `LogListPage.test.tsx` の回帰がないことのみ確認（`npx vitest run src/features/log/LogListPage.test.tsx`）。

## 注意事項
font-family **行のみ**削除。display/-webkit-line-clamp/opacity 等の他宣言は不変。
