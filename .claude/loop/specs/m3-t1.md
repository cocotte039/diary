## 実装概要
- `useLocation().pathname` 判定: `/log` で始まる→「メモ」選択、それ以外→「本棚」選択。
- `<Link to="/">本棚</Link>` / `<Link to="/log">メモ</Link>`、区切り「/」（opacity 0.2）。
- 選択中 opacity 0.85 / 非選択 0.3、transition 120ms（≤200ms）、`font-family: var(--font-family-ui)`、0.8rem。
- 既存 `.app-header-link` の作法と視覚整合（色は4色のみ）。

## 受入条件
- 🔵 pathname `/` で「本棚」が選択状態（opacity 0.85 相当 class）、`/log` で「メモ」選択
- 🔵 `/log/new`・`/log/123` でも「メモ」選択（/log 前方一致）
- 🔵 Link href が `#/` と `#/log`（HashRouter）
- 🔵 4色のみ・transition≤200ms
- 🔵 `npm run test:run` 緑

## テスト方針
HeaderTabs.test.tsx: MemoryRouter で各 initialEntries（'/','/log','/log/new','/log/abc'）→ 選択状態クラス・リンク存在を検証。
