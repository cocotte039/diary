# M4-T1: buildExportPayload に memos（TDD）

## 変更対象
- `src/lib/export.ts`
- `src/lib/export.test.ts`

## 実装概要
`buildExportPayload`:
```ts
const [volumes, pages, memos] = await Promise.all([
  getAllVolumes(), getAllPages(), getAllMemos(),
]);
return { version: EXPORT_FORMAT_VERSION, exportedAt: ..., volumes, pages, memos };
```
`version` は定数 `EXPORT_FORMAT_VERSION`(=2) 参照（直書きしない）。

## 受入条件（TDD）
- 🔵 `buildExportPayload().version===2`（EXPORT_FORMAT_VERSION 経由）
- 🔵 戻り値に `memos: Memo[]` を含む（投入したメモが反映）
- 🔵 memos 0件で空配列（undefined でない）
- 🔵 既存 volumes/pages アサーション維持（回帰なし）
- 🔵 `npm run test:run` 緑

## テスト方針
export.test.ts に memos 投入→payload.memos 検証 + version===EXPORT_FORMAT_VERSION（定数参照で自動追従, E16）。既存テストは定数参照なので緑維持を確認。

## Key Links
getAllMemos(M1-T3)←。exportAllData（SettingsPage 既存ボタン）が buildExportPayload を呼ぶ＝本番接続済み。

## 注意
exportAllData の Blob/ダウンロード処理は不変。payload 組立のみ拡張。
