## シグネチャ
```ts
function useMemoAutoSave(
  memoId: string | null,
  content: string,
  onCreated: (id: string) => void
): { flush: () => Promise<void> }
```

## 実装概要
- debounce `AUTOSAVE_DEBOUNCE_MS`(2000)。
- `memoId===null` かつ `content.trim()!==''` の初回保存: `const m = await addMemo(content)` → `onCreated(m.id)`（呼出側が `navigate('/log/'+m.id,{replace:true})`）。以後は memoId 経由 updateMemo。
- `memoId!==null`: `updateMemo(memoId, content)`。
- `content.trim()===''` かつ memoId===null: 保存しない（空メモ不生成, U3/E8）。
- `lastSavedRef` で同一内容の冗長保存抑止（冪等）。
- `flush()`: 保留中を即保存。
- unmount で timer 解除。
- 保存後 `syncPendingMemosBackground()` を fire-and-forget で呼ぶ（M4-T2 で実体。M2 時点は未実装のため import せず、M4-T3 で配線。本タスクでは TODO コメント + 呼び出し箇所を明示）。

## 受入条件（TDD）
- 🔵 memoId=null + 非空入力 → 2秒後 addMemo 1件、onCreated(id) 呼ばれる
- 🔵 memoId=null + 空/空白のみ → 保存されない（getAllMemos 0件）
- 🔵 memoId 指定 + 編集 → 2秒後 updateMemo、updatedAt 更新
- 🔵 同一内容連続 → 二重保存しない（lastSavedRef）
- 🔵 flush() で即保存（fake timer 不要レベルで保存される）
- 🔵 unmount で timer 解除（保存予約が発火しない）
- 🔵 `npm run test:run` 緑
