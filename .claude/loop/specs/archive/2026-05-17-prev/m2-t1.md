# M2-T1: App.tsx に /log/new・/log/:memoId ルート

## 変更対象
- `src/App.tsx`

## 実装概要
`<Routes>` に追加（`*`→`/` フォールバックは最後尾維持）:
```tsx
<Route path="/log/new" element={<MemoEditorPage />} />
<Route path="/log/:memoId" element={<MemoEditorPage />} />
```
M2-T1 時点で MemoEditorPage 未実装なら最小スタブ（`export default function MemoEditorPage(){return null}`）を `src/features/log/MemoEditorPage.tsx` に置き、M2-T3 で実体化。`/log`（一覧）ルートは M3-T3 で追加。

## 受入条件
- 🔵 `/log/new`・`/log/:memoId` でルーティングエラーなし（スタブでも可）
- 🔵 既存ルート（/, /book/:..., /settings, /read リダイレクト, *）回帰なし
- 🔵 `npm run lint` 緑

## テスト方針
App.test.tsx 既存があれば回帰確認。新規ルート専用テストは M2-T3/M3 で実施。
