# M4-T3: registerOnlineSync 拡張 + useMemoAutoSave 同期配線

## 変更対象
- `src/lib/github.ts`（registerOnlineSync）
- `src/features/log/useMemoAutoSave.ts`（M2-T2 のプレースホルダを実配線）

## 実装概要
1. `registerOnlineSync` の online ハンドラに `syncPendingMemosBackground()` を追加（既存 `syncPendingPagesBackground()` と並列、両方呼ぶ）。
2. useMemoAutoSave: M2-T2 で置いた `// M4-T3: syncPendingMemosBackground()` プレースホルダを実 import + 呼び出しに置換（保存成功直後 fire-and-forget）。

## 受入条件
- 🔵 online イベントで syncPendingMemos が発火（registerOnlineSync 拡張、モック検証）
- 🔵 既存 syncPendingPages の online 発火も維持（回帰なし）
- 🔵 useMemoAutoSave の保存成功後に syncPendingMemosBackground が呼ばれる（grep で本番配線確認＝死蓄関数化しない）
- 🔵 `npm run lint && npm run test:run` 緑

## テスト方針
github.test.ts に registerOnlineSync の online ハンドラ拡張テスト（window dispatch 'online'→両 background 呼出）。useMemoAutoSave.test に保存後 sync 呼出（spy）追加。

## Key Links
syncPendingMemosBackground(M4-T2)←。useMemoAutoSave(M2-T2)/registerOnlineSync が本番呼出元。**本タスクで M2-T2 のプレースホルダが実関数に接続され配線完了**。

## 注意
fire-and-forget（await しない、例外で UI を止めない）。syncPendingPages と並走するが shaCache パス分離・octokit 別呼出で衝突なし（E14）。
