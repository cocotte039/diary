## 実装概要
- `.app-header` に `<HeaderTabs />`。`.body` overflow-y:auto。
- `getAllMemos()` → `createdAt` 降順ソート → `dateKey(createdAt)` でグルーピング、日付降順（新しい日が上）。
- 日付見出し `YYYY/MM/DD`（VolumeCard formatRange 同表記、ローカル日付基準=dateKey）、font-family-ui, 0.75rem, opacity 0.5, margin-top 1.5rem。
- 各メモ行は MemoListItem（M3-T5）。本タスクではグルーピング構造 + 空状態 + MemoListItem へのデータ受け渡しを実装（MemoListItem 未完なら最小行で先行、M3-T5 で差し替え）。
- 空状態: メモ0件で「まだメモがありません」（`.empty`: opacity 0.5, 中央, margin-top 4rem, font-family-ui）。

## 受入条件（TDD）
- 🔵 memos が日付降順グループ・各日内 createdAt 降順で表示
- 🔵 日付見出しが `YYYY/MM/DD`、ローカル日付基準（dateKey）でズレない
- 🔵 メモ0件→「まだメモがありません」表示・クラッシュなし
- 🔵 HeaderTabs 表示（タブで本棚へ戻れる）
- 🔵 `npm run test:run` 緑
