## 実装概要
1. BookshelfMenu.tsx を複製
2. Props を `{ onOpenCalendar }` のみに（onCreateNew 削除）
3. open/rootRef state、外部 pointerdown 閉じ + Escape 閉じ useEffect（add/removeEventListener 対称・cleanup 必須）流用
4. trigger（aria-label="メニューを開く"/aria-haspopup="menu"/aria-expanded={open}）・ハンバーガー SVG 流用
5. menu(role="menu") 内項目を2つに:
   - 「カレンダー」button(role="menuitem", onClick: setOpen(false)→onOpenCalendar())
   - 「設定」`<Link to="/settings" role="menuitem" onClick={()=>setOpen(false)}>`
6. import css を `./MemoMenu.module.css`
