## 実装概要
- `const textareaRef = useRef<HTMLTextAreaElement>(null);` 追加
- textarea(L160-170) に `ref={textareaRef}`
- 新規 useEffect（ロード effect とは分離）:
```ts
useEffect(() => {
  if (!ready) return;
  const ta = textareaRef.current;
  if (!ta) return;
  ta.focus({ preventScroll: true });
  if (!isNew && content.length > 0) {
    ta.setSelectionRange(content.length, content.length);
  }
}, [ready, isNew]);
```
（content 依存にしない＝入力毎再フォーカス防止。eslint exhaustive-deps 指摘時は理由コメントで抑制）
- docstring L29「自動フォーカスなし（…静けさ）」→「ready 後 textarea を自動フォーカス（書く所作の摩擦最小化）。編集時はカーソル末尾」
